# TechPro / Smart Earth — Frontend preview

مشروع HTML وCSS وJavaScript متعدد الصفحات. ليس تطبيق Laravel، ولا يحتوي Backend أو بوابة دفع.

## التشغيل

يتطلب Node.js حديثًا يدعم `node:test`، وPython 3.

```bash
npm ci
npm run dev
```

افتح http://localhost:8000/ . لتشغيل المعاينة بعد بناء الملفات:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

أو شغّل `python3 ruun.py` واختر التشغيل أو الفحص. لا يعتمد السكربت على colorama ولا يحذف سجل Git أو يدفع التغييرات.

## البناء والفحص

```bash
npm run build
npm run check
npm test
npm run verify
```

`tailwind.config.cjs` هو مصدر الثيم للبناء، و`css/tailwind.css` مدخل PostCSS. الملف الناتج `css/generated.css` تستخدمه الصفحات مباشرة. أعد البناء بعد تعديل أصناف HTML/JS. `js/tailwind-config.js` ملف قديم للتوافق مع المراجع وليس جزءًا من التشغيل الحالي.

## أماكن الملفات

- `index.html`: الرئيسية الفعلية.
- `pages/storefront/`: واجهات المتجر الحالية.
- `pages/support/`, `pages/legal/`: صفحات الدعم والسياسات.
- `All/`: تصاميم مرجعية؛ ليست الصفحات المنشورة الحالية.
- `components/`: الهيدر والفوتر المشتركان.
- `js/config.js`, `js/api.js`: وضع التشغيل وطلبات API.
- `js/main.js`: التهيئة وحالة التجارة المشتركة.
- `js/auth-state.js`: حسابات العرض المحلية؛ ليست مصادقة إنتاجية.
- `js/pages/storefront-common.js`: التحويلات وبطاقات العرض العامة.
- `js/pages/catalog-layout.js`: عرض الكتالوج المتخصص بأسماء دوال مستقلة.
- `js/pages/product-demo-profiles.js`: ملفات وصف تجريبية لا تستخدم للمنتجات الحقيقية.
- `tests/`: اختبارات السلوك وترتيب تحميل ملفات الصفحات.

بعض الملفات الموجودة في بقية `pages/` مجرد هياكل أولية. وجود ملف لا يعني أن الميزة منفذة. راجع [حالة الصفحات](docs/PAGE-STATUS.md).

## الديمو والربط الحقيقي

الإعداد الافتراضي `mode: 'demo'` في `js/config.js`: تُجرب قراءات API وتُعرض بيانات تجريبية عند التعذر. الطلبات محاكاة محلية فقط بلا إرسال أو تحصيل أموال. القائمة الفارغة الصحيحة من API لا تستبدل بديمو.

في وضع `live` لا توجد عودة تلقائية للديمو عند الفشل. لا تفعّل مبيعات فعلية قبل تنفيذ عقد الخادم والتحقق منه. راجع [عقد API](docs/API-CONTRACT.md) و[تقرير الإصلاح](docs/REPAIR-REPORT.md).

حسابات العرض الجديدة منفصلة عن مفاتيح الحسابات القديمة، والجلسة محفوظة في localStorage وتبقى بعد التحديث وإغلاق التبويب حتى تسجيل الخروج صراحة أو حذف بيانات الموقع. لكل حساب سلة ومفضلة محليتان منفصلتان عن الزائر. لا تستخدم بيانات شخصية أو كلمات مرور حقيقية للاختبار.
