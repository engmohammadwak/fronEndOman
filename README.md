# TechPro / Smart Earth

متجر تجريبي بواجهات عربية وإنجليزية، مع خادم Node للروابط النظيفة ودخول الإدارة. الكتالوج وإدارة المنتجات والطلبات التجريبية ما زالت محلية في المتصفح؛ ليست قاعدة بيانات متجر إنتاجي.

## التشغيل

```bash
npm ci
npm run setup:admin
npm run dev
```

`setup:admin` يُنفّذ مرة واحدة: أدخل اسم مستخدم، ثم احفظ كلمة المرور المولدة التي تظهر مرة واحدة. لا توجد كلمة مرور افتراضية. يُحفظ تجزئة scrypt مملحة في `data/admin-auth.json`، وليس كلمة المرور. الأمر يرفض استبدال حساب موجود. لا تنشر مجلد `data` أو ملف `.env`.

- المتجر: http://localhost:3000/
- الإدارة: http://localhost:3000/dashboard
- الأجهزة الجديدة: http://localhost:3000/new-devices
- الأجهزة المجددة: http://localhost:3000/refurbished-devices

نقطة التشغيل للإنتاج وcPanel: `npm start` → `node server/api.mjs` (يقرأ `process.env.PORT` ويدعم Passenger/Unix socket، مع `trust proxy` وكوكيز `Secure` خلف HTTPS).

استخدم نفس اسم المضيف دائمًا؛ تخزين `localhost` منفصل عن `127.0.0.1`. يمكن ضبط `HOST` و`PORT` عند الحاجة. `python3 ruun.py` يشغّل نفس سيرفر التطوير. لا تستخدم `python -m http.server` لأن الروابط المختصرة وواجهة دخول الإدارة تتطلب خادم المشروع.

الروابط القديمة تحوّل إلى الروابط المختصرة مع حفظ معاملات البحث. أسماء الملفات الداخلية لا تظهر في روابط التنقل الحالية. الصفحة الرئيسية لا تتضمن رابطًا للإدارة.

## الجلسات

دخول الإدارة يُتحقق منه على السيرفر. Cookie من نوع `HttpOnly; SameSite=Strict` بصلاحية 30 يومًا تستمر بعد تحديث الصفحة وإعادة تشغيل السيرفر، وتُلغى عند Logout. تُضاف `Secure` تلقائيًا عند `TECHPRO_PUBLIC_URL=https://...` أو `COOKIE_SECURE=1` أو عند اكتشاف HTTPS عبر `X-Forwarded-Proto` خلف بروكسي cPanel.

حسابات العملاء الحالية **تجريبية محلية** في `js/auth-state.js`؛ الجلسة والسلة والمفضلة تبقى بعد التحديث وإغلاق التبويب. حذف بيانات المتصفح يلغي هذا التخزين. يلزم Backend لحسابات العملاء قبل استقبال عملاء حقيقيين.

## الدفع وحالة التسليم

إنشاء الطلبات الحقيقية والدفع محجوبان حاليًا باستجابة 503: الكود السابق كان يثق بالسعر المرسل من المتصفح. `/api/payments/config` يُعلن أن الدفع غير مفعّل حتى تكتمل أسعار ومخزون السيرفر والتحقق من ملكية الطلب. حفظ مفاتيح Paymob المشفرة واختبارات HMAC لا تعني أن الدفع جاهز للإنتاج.

راجع [المراجعة الأحدث](docs/REVIEW-2026-09-10.md) و[تقرير التسليم](docs/ENTERPRISE-HANDOVER.md) و[تدقيق المشكلات](docs/ENTERPRISE-AUDIT.md) قبل النشر.

## البناء والفحص

```bash
npm run build
npm run check
npm test
npm run verify
```

تحتاج اختبارات HTTP السماح بفتح منفذ loopback مؤقت. `tailwind.config.cjs` مصدر الثيم، و`css/tailwind.css` مدخل PostCSS، و`css/generated.css` الناتج المحلي. لا يستخدم التطبيق Tailwind CDN.

## البنية

- `js/app-routes.js`: خريطة الروابط المشتركة بين المتصفح والخادم.
- `scripts/server.mjs`: تقديم الصفحات والأصول ورفض الملفات الخاصة.
- `server/admin-auth.mjs`: التحقق والجلسات ومحدّد محاولات الدخول.
- `server/api.mjs`: HTTP API؛ `server/db.mjs`: التخزين المحلي على السيرفر.
- `pages/storefront/`, `pages/support/`, `pages/legal/`: الصفحات الحالية.
- `components/`: الهيدر والفوتر المشتركان.
- `js/pages/`: متحكمات الصفحات وعرض البيانات.
- `js/admin/admin-*.js`: وحدات الإدارة مقسمة حسب الوظيفة.
- `js/admin/store-state.js`: مستودع البيانات التجريبي المحلي.
- `All/`: تصاميم مرجعية غير منشورة. بعض ملفات `pages/` هياكل مخططة؛ راجع [حالة الصفحات](docs/PAGE-STATUS.md).
