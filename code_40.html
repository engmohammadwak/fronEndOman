محرر استعلامات ClickHouse السريع (OLAP Query Console)

استعلام فوري مباشر على ملايين السجلات بدون أي إبطاء لخوادم الإنتاج

SELECT device_brand, condition_grade, COUNT(order_id) AS units_sold, ROUND(SUM(total_amount_sar), 2) AS gross_revenue

FROM techpro_dwh.sales_fact

WHERE order_timestamp >= '2025-01-01'

GROUP BY device_brand, condition_grade ORDER BY gross_revenue DESC LIMIT 3;
