# 🇴🇲 fronEndOman

TechPro UI Screens - Frontend Prototype

## Structure

Vanilla HTML, CSS and JavaScript frontend.

### Main Directories

- `pages/` - Website pages
- `components/` - Reusable components
- `assets/` - Images, icons and fonts
- `css/` - Stylesheets
- `js/` - JavaScript
- `index.html` - Main page

## Technologies

- HTML5
- CSS3
- JavaScript
- Vanilla JavaScript
- Responsive Design

## Git Safety

Do NOT use force push.

Never use:

git push --force

Use:

git status
git add .
git commit -m "Update UI screens"
git push origin main
