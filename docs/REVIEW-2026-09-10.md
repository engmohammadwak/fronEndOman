## المرحلة الثالثة: التحقق

- `npm run verify`: نجح البناء وفحص syntax والمراجع المحلية والمعرّفات؛ **110 اختبارات ناجحة**.
- اختبار تشفير جديد: القراءة الصحيحة، رفض تعديل النص المشفر، رفض المفتاح المفقود وعدم إنشاء مفتاح بديل.

اختبار Chrome النهائي نجح على عرضَي 390 و1440: صفحات المتجر الأساسية، رسالة عدم إعداد حساب الإدارة (503)، الدخول والتحديث، صفحات الإدارة، تغيير اللغة، ثم تسجيل الخروج. لا أخطاء JavaScript ولا تجاوز أفقي في الحالات المختبرة بعد إصلاح الخلفية. طلبات الشبكة الملغاة أثناء التنقل لا تثبت تعطل موارد الموقع؛ لم يُجرَ اعتماد شامل لكل الصور والخطوط الخارجية.
